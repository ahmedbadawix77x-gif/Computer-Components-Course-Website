# Computer Components Course Website

**An Arabic multi-page educational website about computer components, built for a university computer course. It extends the course-project template with lesson media (audio and video).**

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## Pages

Home, introduction, lesson content, activities, library, quiz, about and contact. The `video/` folder holds the lesson audio (`lesson.mp3`) and video (`lesson.mp4`).

## Run it

```bash
git clone https://github.com/ahmedbadawix77x-gif/Computer-Components-Course-Website.git
cd Computer-Components-Course-Website
python -m http.server 8000
```

Static HTML and CSS, no build step. Arabic, right-to-left.
